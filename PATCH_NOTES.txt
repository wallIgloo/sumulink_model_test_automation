Whitespace-preserving CUT path fallback

Resolution policy:
1. Preserve the Excel CUTPath exactly and check whether the Simulink block exists.
2. If not found, apply the previous outer strtrim behavior and check again.
3. If both fail, return the legacy-trimmed candidate so existing validation reports a normal not-found error.

Changed files:
- st_load_targets.m
  CUTName/CUTPath no longer lose trailing whitespace while being loaded.
- st_normalize_cut_path.m
  Exact path first, legacy trimmed path second.
- st_fill_temp_paths_from_indent.m
  Preserves actual CUTName whitespace when constructing temporary paths.

Example:
Actual block = 'Child '
Excel CUTPath = 'TEST_TARGET_MODEL_NAME/Parent/Child '
=> exact candidate wins.

Actual block = 'Child'
Excel CUTPath = 'TEST_TARGET_MODEL_NAME/Parent/Child '
=> exact candidate fails, trimmed candidate wins.
