Test Manager incremental update patch

Default:
    cfg.OverwriteTestFile = false

OverwriteTestFile = false
- If the target .mldatx is already open, reuse that TestFile object.
- If it exists but is not open, open it.
- If it does not exist, create it.
- Preserve existing Test Cases in cfg.TestSuiteName.
- If TestCaseName already exists in that suite, SKIP it unchanged.
- Create only missing Test Cases.
- Duplicate TestCaseName rows in the same Excel input are also skipped after
  the first one is created.

OverwriteTestFile = true
- Close only the target Test File if it is already open.
- Recreate the .mldatx file.
- Rebuild the requested suite's Test Cases from Excel.

Result additions:
- ExistingTestCase
- Action = CREATED / SKIP_EXISTING / FAILED
- Status = OK / SKIP / FAIL

Note:
cfg.RunGeneratedTests = true may still run existing enabled Test Cases in the
Test File, depending on the existing execution flow. This patch only changes
Test Manager creation/update behavior.
